# SQL Playground — External Admin Dashboard

A standalone monitoring dashboard located completely outside `hospital_db_sql`.

## Run Locally

```powershell
cd G:\SQL-PLAYGROUND\admin-dashboard
npm start
```

Then open **http://127.0.0.1:4000** in your browser, enter your SQL Playground backend URL (for example `http://localhost:5000` or your live `https://your-app.vercel.app` URL), and unlock with `ADMIN_SECRET`.
